<objective>
Extend the agent data layer with four optional fields so external AgentCore runtimes can be stored as agent records: `agentType`, `externalRuntimeArn`, `externalRuntimeRegion`, `streamFormat`. This covers the type definitions, the repository update patch, the DynamoDB marshal/unmarshal write path, and the Zod request validation schemas. No DynamoDB table migration is needed — DynamoDB is schemaless and existing rows simply lack the new (optional) fields.

Purpose: Establishes the stable schema contract that the invoke proxy route (plan 03), the sharing assertions (plan 04), and the entire Phase 2 frontend will build against.
Output: Updated type/repository/marshal/route files plus extended unit tests proving the new fields round-trip.
</objective>
